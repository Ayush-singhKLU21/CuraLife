SETUP
1. Extract this ZIP.
2. Copy the HTML files into the root of your Health Record System project.
3. Copy css/style.css into your existing css folder (replace the old style.css).
4. Copy all JS files into your existing js folder.
5. Open index.html in VS Code and run with Live Server.

IMPORTANT
This is a client-side academic demo. LocalStorage and browser-side passwords are NOT secure.
Do not store real patient data, medical records, passwords or confidential information.
For a real system, use a secure backend, proper authentication, authorization, encryption,
audit logging and privacy/legal review. Google Fonts are optional; local fallback fonts apply.
